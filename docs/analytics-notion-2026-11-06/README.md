# Notion 구성 파일

- `events.csv`: 이벤트 10개. 한 행은 이벤트 하나이며, 코드 연결과 운영 수신은 별도 속성이다.
- `parameters.csv`: 퍼널 매개변수 7개.
- 상위 `GA_TRACKING_PLAN_2026-11-06.md`: 화면 16개와 조건을 함께 정리한 본문.

Notion CSV 가져오기로 이벤트·매개변수 데이터베이스를 만들 수 있다. 가져오기 이후 유형과 뷰 설정은 별도 작업이다.

권장 뷰: 전체 이벤트 표 / 운영 수신이 ‘기간 내 미관측’인 확인 대기 표. 이벤트명은 제목, 사이트·코드 연결·운영 수신은 선택, 수신 건수는 숫자, 나머지는 텍스트로 설정한다. 미관측 건수는 빈칸을 유지한다. 화면은 본문의 2열 화면·이벤트 표를 유지하며, 필요할 때만 화면 갤러리로 전환한다.

이 파일은 Notion에 반영되었다는 증거가 아니다. 실제 반영 여부는 작업 결과를 따른다.
