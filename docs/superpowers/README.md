# docs/superpowers — 아카이브 (현행 스펙 아님)

이 디렉터리(`plans/`, `specs/`)는 작업 시점의 **계획·스펙 산출물 스냅샷**이다. 특정 시점의 의사결정 기록일 뿐, **현행 제품/기술 스펙이 아니다.**

- 에이전트·기여자 주의: 여기 있는 문서를 "현재 진실"로 신뢰하지 말 것. 반드시 **코드·테스트**, 그리고 캐노니컬 문서(`CLAUDE.md`, `SCREEN_DESIGN.md`, `DESIGN.md`)와 대조한 뒤 사용한다.
- 과거형으로 읽는다: "이 계획대로 했었다"가 아니라 "이 시점에 이렇게 계획했다".
- 현행 진입점은 루트 `CLAUDE.md` 의 "Documentation Map" 이다.
