# 선정 확인창

로그인한 구매사의 실제 `/rfp/P-2604-0001` 페이지에서 촬영했습니다. `/demo` 화면이 아닙니다.

- 환경: 변경 브랜치를 로컬에서 실행하고, 격리한 임시 Postgres에 기존 테스트 시드를 적재
- 화면 크기: 모바일 390×844, 데스크톱 1440×900
- `collapsed-*`: 기본으로 접힌 합의서 문안
- `expanded-*`: 전문을 펼치고 키보드로 하단 선정 버튼에 접근한 상태
- 견적 확정은 실행하지 않았으며 운영 데이터는 사용하지 않았습니다.
- 시드 견적에는 카드 요율이 없어 기존 대체 문구인 “견적에서 확인해요”가 표시됩니다.
