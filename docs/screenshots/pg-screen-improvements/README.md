# PG 로그인 후 화면 개선

2026-10-30 Playwright Chromium으로 로그인한 PG 화면을 캡처했다. 로컬 개발 서버와 `supporter_b_test`의 가상 구매사·PG 데이터를 사용했다. 메시지와 알림도 테스트 DB 표시용 데이터다.

| 파일 | 화면 | 크기 |
|---|---|---|
| `inbox-desktop-light.png` | 상태 필터를 먼저 보여주는 받은 견적 요청과 카드 작업 영역 | 1440×1000 |
| `workspace-desktop-dark.png` | 요청 조건·견적 작성 패널 제목, 작성 단계와 하단 행동 | 1440×900 |
| `template-desktop-light.png` | 이름 → 정산조건 → 수수료, 등급별 5열 입력 | 1440×900 |
| `home-mobile-light.png` | 균등 KPI 3개, 응답 필요 총건수와 전체 보기 | 375×900 |
| `template-mobile-light.png` | 등급별 2열 입력과 고정 저장 행동 | 375×900 |
| `notifications-mobile-light.png` | 업무 분류·제목·내용·시각·읽음 상태 | 375×900 |

375·768·1280·1440px의 밝은/어두운 테마와 모션 감소 설정에서 확인했다. 키보드 오류 초점 이동, 템플릿 메뉴 닫기 후 포커스 복귀, 모바일 메시지 검색·선택 유지, 작성 단계·입력·스크롤 보존도 검증했다. 1440px 화면의 200% 확대에 해당하는 720 CSS px / 배율 2 환경에서 넘침을 확인했다.

로컬 Turbopack 인터셉트 라우팅에서 견적번호에 `(.)`가 붙는 기존 현상이 재현됐다. 상세 이전·다음 이동은 별도 Webpack 개발 서버에서 정상 확인했다. 전체 단위 테스트 9,313건, PG 견적 제출·튜토리얼 E2E 7건, 타입 검사와 lint가 통과했다.
