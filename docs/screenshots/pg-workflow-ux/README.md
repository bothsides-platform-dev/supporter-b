# PG 핵심 업무 화면

2026-10-30 Playwright Chromium에서 로그인한 PG의 실제 `/inbox`와 `/inbox/P-2604-0001` 화면을 캡처했다. 개발 서버와 `supporter_b_test` 테스트 DB의 가상 구매사·PG 시드를 사용했다.

| 파일 | 화면 | 크기 |
|---|---|---|
| `pg-inbox-1440.png` | 개별 마감이 있는 수정 요청을 검색한 카드 목록 | 1440×900 |
| `pg-inbox-390.png` | 같은 수정 요청의 모바일 카드 목록 | 390×900 |
| `pg-fees-1440.png` | 요청 정보와 견적 작성의 40:60 배치, 구매사 등급 강조 | 1440×900 |
| `pg-fees-390.png` | 초안 복원 뒤 모바일 수수료 입력과 하단 행동 | 390×900 |

- 목록 캡처: `e2e/scenario-e-requote.spec.ts`
- 작성 캡처: `e2e/scenario-b-pg-bid.spec.ts`
- 각 시나리오는 1280·1440·390px에서 실제 제출과 DB 결과까지 확인한다.
- 시드에 업종·요청 결제수단·운영 정보가 없는 항목은 화면에 `미제공`으로 표시된다. 작성기의 결제수단은 기존 전체 수단 입력 규칙을 따른다.
- 운영 고객 데이터나 운영 발송을 사용하지 않았다. 실제 PG 담당자 사용성 테스트 결과를 뜻하지 않는다.
